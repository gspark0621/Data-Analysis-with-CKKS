## 0. 전체 흐름

```
클라이언트                          서버 (암호문만 봄)
─────────                          ──────────────────
분위수 구간화 (n_max)
subsample 비율 결정
one-hot 인코딩 + 암호화   ──────→   ① prefix 누적합      (비교 없이 회전만)
                                    ② 레벨 루프 × D
                                        T1  파티션 통계
                                        T2  분할 점수
                                        T3  argmax
                                        T4  모델 좌표계로
                                        T5  마스크 갱신 (방식 C)
                                    ③ T6 리프값 (Goldschmidt)
                                    ④ 부스팅 라운드 반복 × T
모델 복호 / 또는 서버 추론  ←──────   Model, Theta, Leaf
```

**위협 모델**: 비대화형. 서버는 학습 전 과정에서 복호하지 않는다.
**공개 파라미터**: `n, d, n_max, D, T, M(체인), subsample, mtry, λ, lr`.

## 1. 레이아웃

### 1-1. 학습 좌표계 ✅

```
slot[ (j·n_cat + b)·S + l ] = 1   iff   bin(x_lj) == b

  j ∈ [0,d)      feature
  b ∈ [0,n_cat)  bin,     n_cat = 2^⌈log2 n_max⌉
  l ∈ [0,S)      sample,  S = min(2^⌈log2 n⌉, M)
```

**두 단계 타일링** — 모든 n 을 수용.

| 경로 | 조건 | 예 |
|---|---|---|
| 기본 | `per_ct ≥ n_cat` (n_cat 배수로 내림) | cancer 379 → per_ct 64, 타일 4 |
| feature 분할 | `per_ct < n_cat` (2의 거듭제곱) | adult 22,793 → per_ct 1, 타일 48 |
| 샘플 청크 | `n_pad > M` | sepsis 77,239 → 청크 4, 타일 96 |

★ **subsample 은 최적화가 아니라 제약이다.** sepsis sub=0.1 → 타일 96 → 6 (16배).

### 1-2. 모델 좌표계 ✅

```
Model[ t·dp + f ] = 1  iff  f == j_t       dp = 2^⌈log2 d⌉
Theta[ t·dp ]     = (k_t + 1) / n_max
Leaf [ ℓ·dp ]     = 리프값                  ℓ ∈ [0, 2^D)
```
★ symmetric → 레벨당 분기 하나 → 모델 `D·dp` 슬롯 (비대칭은 `2^D·dp`).

## 2. 학습

### T0. subsample ⚠️ 인터페이스만

공개 난수 마스크 (pt 곱 1회). T1 비용이 n 에 직접 비례.

```
        n_tr <  10,000   →  1.0
10,000 ≤ n_tr <  50,000  →  0.5     (손실 −0.011)
50,000 ≤ n_tr < 200,000  →  0.25    (−0.011)
        n_tr ≥ 200,000   →  0.1     (−0.011)
```
★ d 에 크게 의존 (d=3 이면 110k 에서 0.1 이 −0.0004). 클라이언트가 평문 CV 로 결정.

### ① prefix 누적합 ✅ 오차 0

```
b 축 누적합 → slot[(j·n_cat+k)·S + l] = [ bin(x_lj) ≤ k ]
```
**비교 없이 회전/덧셈만.** `per_ct=1` 이면 회전 0회 (타일 간 carry = 덧셈).

### T1. 파티션별 통계 ✅ 오차 0

```
분류    L_q = Σ_l m_p·y_q·pre_{j,k}        선택 벡터 c 개
부스팅  G   = Σ_l m_p·g  ·pre_{j,k}        선택 벡터 2 개
        H   = Σ_l m_p    ·pre_{j,k}
```
타일당 **곱 1 + log₂(S) 회전**. 샘플 청크는 덧셈 합산.
★ 다중 클래스일수록 부스팅이 싸다 (soybean c=15 → 2).

### T2. 분할 점수 ✅ FHE 검증

```
분류    MGI   Σ_p [ L(L−N) + Σ_q L_q(N_q−L_q) ]        argmin
        ★ 인수분해로 ct·ct 곱  2c+2 → c+1

부스팅  gain  Σ_p ( G'_L·H'_p − G'_p·H'_L )²           argmax
        ★ 항등식  ΣG²/H − G_p²/H_p = (G_L H_p − G_p H_L)²/(H_L H_R H_p)
          분자만 쓰면 나눗셈 소멸.  정확한 gain 대비 −0.016~+0.004
        ★ 분류 MGI 를 부스팅에 쓰면 −0.025~−0.127, 깊을수록 악화 → 금지
```

### T3. argmax 🟡 league 구현, 레벨 0 통과

⚠️ **깊은 레벨에서 트리가 평문과 어긋난다.** `SCORE_TIGHTEN` 보정이 고정 표라
   레벨·데이터셋에 안 맞는다.  α 측정 실험으로 확정 전까지 `ARGMAX_MODE="plain"`.

```
league(전쌍):  ind_i = Π_{j≠i} [ s_i ≥ s_j ]
  · sign 을 SIMD 로 1회   (토너먼트 log₄ns, Masalha log₂log₂ns 보다 적음)
  · ns² ≤ M  →  mtry=√d 필요 (cancer ns 210→35, ns² 1,225)
  · ★ α(top) 만 필요 — 근접 동점이 전부 패자끼리라 결과에 안 나타난다
        i=최댓값 :  모든 인자가 깨끗한 1  →  ind=1
        i≠최댓값 :  [s_i ≥ s_max] 가 깨끗한 0  →  ind=0 (흐린 인자는 소멸)
```

측정 (분위수 8구간, iris/wine/cancer/sepsis모양):

| 형태 | α(top) | α(min) | ct·ct 곱 |
|---|---|---|---|
| **a² (채택)** | **5~7** | 16~23 | **1** |
| \|a\| | 6~9 | 9~15 | sign 1 + 곱 1 |

★ league 면 α(min) 불필요 → **a² 가 α·연산 모두 유리**.

### T4. 모델 좌표계 전환 🟡 20/20

```
θ         가중치 pt곱 → 블록 합(log₂ per_ct) → slot[t·dp]
onehot_j  k 축 합 → feature 그룹 → stride 압축 → slot[t·dp + j]
```
★ symmetric 이라 레벨당 1회, 청크 불필요.

### T5. 마스크 갱신 — 방식 C ✅ 오차 0

```
m_left  = m_p ⊙ b            곱 1회
m_right = m_p − m_left       ★ 뺄셈
L[2p+1] = L[p] − L[2p]       ★ 대수적 항등식, 오차 0
N[2p+1] = N[p] − N[2p]       broadcast_total 이 선형
```
레벨 t+1 에서 `2^t` 개만 계산. **마지막 레벨은 마스크만.**

### T6. 리프값 🟡 오차 1e-16

```
leaf[ℓ] = + lr · G[ℓ] / (H[ℓ] + λ)        λ = n/2^D (공개)
```
★ **부호 규약**: G 는 **잔차 합**(y−F). gradient(F−y) 를 넣으면 발산.
★ λ 가 분모 하한을 만들어 `H+λ` 범위를 `(2^D+1):1` 로 압축 → Goldschmidt `D+5` 회.

| | 반복 | ct·ct 곱 | 깊이 | 상대오차 |
|---|---|---|---|---|
| D=4 | 9 | 16 | 12 | 3e-14 |
| D=6 | 11 | 20 | 14 | 1e-14 |
| D=10 | 15 | 28 | 18 | 9e-15 |

**기각된 대안** (전부 깊이에서 실패):

| 방법 | 나눗셈 | D=4 손실 | 이유 |
|---|---|---|---|
| 기대 크기 `G·2^D/n` | 없음 | −0.030 | 리프 크기 편차 무시 |
| sign + 고정 스케일 | 없음 | −0.046 | 잔차 감소를 못 따라감 |
| sign + 전역 스케일 | 없음 | −0.040 | 리프별 편차 못 담음 |
| Richardson `v+=η(G−Hv)` | 없음 | 발산 | 조건수 2^D → 반복 O(2^D) |

★ Richardson 이 **soft tree 가 400 에폭을 돌려야 했던 이유**와 같다 (같은 1차 반복).

### T4-b. 하이브리드 부스팅 ❌ 미구현

```
체인 M 개 슬롯 병렬, 각 T 라운드 → 예측 평균
  M=K,T=1 배깅 / M=1 순수 부스팅 / M=4 권장
```
평문 (순차 T=16): 배깅 0.701 < 부스팅 0.783 < **하이브리드 M=8 0.811** ≈ 부스팅 T=64 0.810.
★ `n_pad ≥ M_slots` 이면 체인이 순차가 되어 이점 소멸 (대규모 주의).

## 3. 추론 ✅ 실제 FHE 20/20

```
I1  입력을 D 블록에 복제                       회전 log₂D
I2  feature 선택 ⟨Model, x⟩                    ct·ct 1 + 블록합
I3  비교 sign(Sel − Theta)                     ★ 트리 전체에 1회
I4  b_t 를 전 리프에 복제 후 β 와 XOR           ★ stride 확장 불필요
```

★ **마진이 binning 으로 보장**된다 — `θ=(k+1)/n_max`, `x=(b+0.5)/n_max`
  → `|x−θ| ≥ 1/(2·n_max)` → 추론 sign α=4~8.
  **argmax 와 성격이 완전히 다르다** (그쪽은 보장 없음).

```
       비대칭 노드평가  symmetric   배율      모델 슬롯
D=6         63             6      10.5x     2,016 → 192
D=8        255             8      31.9x     8,160 → 256
D=10     1,023            10     102.3x    32,736 → 320
```

## 7. 정리된 논거

```
① 노드 표현 (onehot_j, θ)   모델·추론이 depth 에 대해 지수 → 선형
② symmetric tree            argmax 호출 2^D−1 → D  (D=6 에서 10.5배)
③ left-only MGI             오른쪽 자식 통계 불필요.  오차 0 항등식
④ 방식 C                    오른쪽 파티션은 뺄셈.     오차 0 항등식
⑤ 부스팅 gain 항등식        나눗셈 없는 분할 기준.    −0.016~+0.004
⑥ league argmax             α(top) 만 필요.  sign SIMD 1회
⑦ binning 마진              추론 sign α=4~8          (선행연구 α≈20)
⑧ NAF 회전 분해             임의 shift 회전 0
```

**주장** — 같은 정확도에서 **depth 12까지** 학습·추론 가능하고 모델이 100배 작다.
대규모에서 depth 6 → 12 가 **정확도 +0.074**.

**못 이기는 것** — 학습 총시간(Masalha), sepsis(d=3 이라 깊이 이득 +0.005), argmax 자체.
